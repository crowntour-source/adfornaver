# K-Name & K-Match

케이팝·한국을 좋아하는 해외 팬을 위한 재미용 웹사이트입니다. 빌드 없이 `index.html`을 열거나 정적 호스팅에 올리면 동작합니다.

- **My Korean Name**: 이름·성별·분위기(귀여운/멋진/우아한/밝은/강인한)·생년월일(선택)로 한국 성 + 이름을 추천
  (한글, 로마자, 한자·병음, 뜻, 복사 버튼). 순우리말 이름(하늘, 보라 등)도 포함.
- **K-Match**: 나와 최애/짝사랑/친구의 생년월일로 띠 + 별자리 원소 + 생명수 기반 궁합 점수
- 지원 언어: EN · 한국어 · ไทย · Tiếng Việt · Bahasa Indonesia · 中文 · FR · ES
  (`?lang=th` 쿼리 → 저장된 선택 → 브라우저 언어 순으로 적용, 말레이어 브라우저는 인도네시아어로 연결)

## 파일 구조
- `data.js`: 언어와 무관한 데이터(이름 목록, 한국 성, 별자리 날짜)
- `lang/<code>.js`: 언어별 문구·띠·별자리·오행·한자 뜻·순우리말 뜻 (언어 하나 = 파일 하나)
- `app.js`: 계산·화면 / `style.css` / `index.html`

## 새 언어 추가 (예: 말레이어 ms, 필리핀어 fil, 미얀마어 my, 크메르어 km)
1. `lang/en.js`를 복사해 `lang/ms.js`로 만들고 값을 번역 (`registerLang('ms', {...})`, `htmlLang` 지정)
2. `index.html`에 `<script src="lang/ms.js"></script>` 추가
3. 누락된 키는 영어로 자동 대체되므로 일부만 번역해도 동작합니다.
태국어·미얀마어·크메르어는 `style.css`의 글꼴 목록에 해당 폰트를 추가하세요.

## 주의
재미·팬심용이며 예측이나 전문 상담이 아닙니다. 특정 아티스트·소속사와 무관합니다.
한자 이름은 실제 출생신고용이 아니므로 인명용 한자 여부를 따로 확인해야 합니다.
