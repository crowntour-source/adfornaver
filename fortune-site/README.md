# 궁합 · 작명 (Compatibility & Name Finder)

5개 언어(English · 한국어 · 中文 · Français · Español)를 지원하는 정적 웹사이트입니다. 빌드 없이 `index.html`을 열거나 아무 정적 호스팅에 올리면 동작합니다.

- **궁합**: 띠(입춘 2/4 기준) + 서양 별자리 원소 + 생명수 + 이름 가중치로 점수와 조언을 표시
- **작명**: 출생일의 오행을 계산해 보완 오행의 한자 이름을 추천(뜻은 5개 언어로 표시)
- 언어 선택: 우측 상단 버튼, `?lang=ko` 쿼리, 브라우저 언어 순으로 적용

파일: `data.js`(띠·별자리·한자·이름 데이터), `i18n.js`(UI 문구), `app.js`(계산·화면), `style.css`.
새 언어 추가 시 `data.js`의 각 배열/`GLOSS`와 `i18n.js`에 같은 순서로 항목을 추가하세요.

결과는 오락·참고용입니다. 한자 이름은 출생신고 전 인명용 한자 여부를 확인하세요.
