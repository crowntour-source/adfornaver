# 원페이지 광고 한글화 도구

영문 원페이지 광고 **URL만 넣으면** 한글 페이지로 바꾸고, 페이지 속 **영상도 한글화**(자막·더빙·화면 글자 교체)한 뒤 **브라우저에서 바로 수정**할 수 있는 웹 도구입니다.

## 실행

```bash
cd page-translator
npm install
cp .env.example .env      # 키 입력
npm start                 # http://localhost:3100
```

| 키 | 용도 | 없으면 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 번역, 화면 속 글자 인식 | 사용 불가 |
| `OPENAI_API_KEY` | 음성 인식(Whisper), 한글 더빙(TTS) | 화면 글자 교체·수동 자막만 가능 |

YouTube/Vimeo 링크는 서버에 `yt-dlp`가 있어야 내려받습니다(mp4 직접 링크·파일 업로드는 불필요).
자바스크립트로 그려지는 페이지는 옵션의 "브라우저로 렌더링"을 켜세요(`npm i playwright && npx playwright install chromium`).

## 사용법

**① 페이지**: URL 입력 → "한글로 변환" → 미리보기에서 문구를 직접 클릭해 고치거나 오른쪽 목록에서 수정 → 이미지 클릭으로 교체 → "HTML 다운로드".
말투·용어집(브랜드명 고정 등)을 옵션에 넣을 수 있습니다.

**② 영상**: 페이지 속 영상의 "영상 한글화 →" 클릭(또는 URL/파일 입력) → 분석(음성 인식·번역, 화면 영어 글자 위치 검출) →
내레이션 문구·시간, 화면 글자 문구·위치·색을 수정 → "한글 영상 만들기" → 미리보기/다운로드. SRT 자막도 받을 수 있습니다.

## 한계 (반드시 확인)

- 이미지·영상 안에 **박혀 있는 글자**는 자동 인식이 틀릴 수 있어 위치/문구 확인이 필요합니다. 이미지 속 글자는 직접 교체하세요.
- 페이지는 **정적 스냅샷**(스크립트 제거)입니다. 폼 전송·팝업 등 동적 기능은 동작하지 않으며, 결제/신청 링크는 원본 그대로입니다.
- 번역문의 **이름·날짜·가격·수치는 게시 전에 반드시 원문과 대조**하세요. 원문에 없는 효능/혜택이 생기지 않았는지도 확인이 필요합니다.
- 타인의 광고·영상은 저작권이 있을 수 있습니다. 사용 허락이 있는 콘텐츠에만 사용하세요.
- 더빙은 API 비용이 발생합니다(영상 길이에 비례).
